2. Zombie Process

Child terminates immediately via exit(42) while parent sleeps without wait(). Inspects Z (defunct) state in /proc before reaping.

Kernel State 'Z'
Anomaly Demo

3. Orphan Process

Parent process exits immediately while child runs. Child is orphaned and adopted by init / systemd (PPID changes to 1 or subreaper).

Init Adoption
Monitoring

4. Non-Blocking Wait

Parent uses waitpid(pid, &status, WNOHANG) to perform background tasks without freezing while child executes concurrently.

WNOHANG Polling
