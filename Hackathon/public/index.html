1. pipe()

Creates an in-memory kernel buffer connecting the output of one process to the input of the next.

2. fork()

Spawns independent child processes concurrently so all commands execute simultaneously.

3. dup2()

Redirects standard input (FD 0) and standard output (FD 1) to the pipe descriptors.

4. close() & waitpid()

Closes unused pipe ends to prevent reader deadlock on EOF and harvests child exit statuses.
